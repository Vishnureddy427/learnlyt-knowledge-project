# LearnLyt – Knowledge Retention Tool

A beginner-friendly project built with HTML, CSS and JavaScript.

## Run in VS Code
1. Extract `LearnLyt_Knowledge_Retention_Tool.zip`.
2. Open the extracted folder in Visual Studio Code.
3. Open `index.html` in a browser, or install the **Live Server** extension in VS Code.
4. Right-click `index.html` and select **Open with Live Server**.

No database or backend setup is required. Your topics, notes and flashcards are saved in your browser using Local Storage.

## Main files
- `index.html` – page structure
- `style.css` – design and responsive layout
- `script.js` – topics, flashcards, quiz, revision and local storage logic

## Notes
- Data is stored in the browser on the device where you use the project.
- Clearing browser site data may remove saved project data.
- The quiz is generated from saved flashcards. Add at least two flashcards to use quiz mode.
